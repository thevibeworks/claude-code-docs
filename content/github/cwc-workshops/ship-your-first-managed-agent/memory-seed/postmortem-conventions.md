# Postmortem conventions

- Blameless. Name the commit, never the person. Write "commit a1b2c3d", not an author name or email.
- Times are UTC, written HH:MM:SS.
- One incident per root cause. If two pages share a root cause, write them up as one incident and list the second page as a symptom.
- Every action item has an owner team and a priority.
- If a follow-up from an earlier postmortem would have prevented this one, say so and link the earlier incident.
