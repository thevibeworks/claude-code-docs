# Config at the tenant level

> Set tenant-wide defaults for product behavior, lock settings so organizations can't change them, and preview how a change affects each organization.

> **Who this is for:** Tenant administrators who set and enforce product settings across every organization in their tenant.

In the tenant view of the admin portal, go to **Settings > Config** to set tenant-wide defaults for product behavior, [lock](https://claude.com/docs/government/config/overview.md#locks) settings so organizations can't change them, and [preview](https://claude.com/docs/government/config/overview.md#previewing-impact) how a change would affect each organization.

The Config page works the same way at the tenant and organization levels, with the same list of settings. See [How Config works](https://claude.com/docs/government/config/overview.md) for how levels, locks, and groups combine, and [Available settings](https://claude.com/docs/government/config/settings.md) for what each setting does.

To open an organization's Config page and act on that organization's behalf, select **Switch to org view**, choose the organization, and go to **Settings > Config**.
