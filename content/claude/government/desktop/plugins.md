# Plugins in Claude Desktop

> Find, install, create, and remove plugins in Claude Desktop for Claude for Government, and understand what plugins add in this deployment.

> **Who this is for:** Anyone who uses Claude Desktop in Claude for Government and wants to find, install, or create plugins.

A plugin is a package that adds capabilities to Claude in a single step, such as skills, slash commands, sub-agents, and hooks. Plugins work in Cowork and in Code. Skills from your organization's plugins also work in Chat, on Claude Desktop 1.44121.4 or later. [What a Chat conversation can reach](https://claude.com/docs/third-party/claude-desktop/chat.md#what-a-chat-conversation-can-reach) says what else a plugin adds there.

## Find and install plugins

Claude for Government does not include a public plugin marketplace; your administrators add your organization's plugins. Go to **Customize > Plugins** to see the plugins you have installed. To find the rest, select **Discover** (**Browse** on Claude Desktop versions earlier than 2.2553.0) and open the **Organization** tab, which lists every plugin your administrators have made available to you.

A plugin your administrators set to install automatically is already installed. A plugin they offer for you to choose stays available until you install it. If a plugin you expect is missing, ask your organization's owner.

If your administrators let you add your own plugins, **Add** on the same page lets you install a plugin from its `.zip` file or have Claude build one. If those options are missing, your administrators haven't allowed them. A plugin you upload or create is added only on the device you are using. Claude Desktop shows a notice reminding you to install only plugins you trust, since uploaded plugins are not controlled by Anthropic.

If your administrators let you add plugin marketplaces, you can add a marketplace of your own from **Discover**. Whether a marketplace you add can be downloaded depends on your agency's network and on the settings your administrators choose.

## Manage installed plugins

Go to **Customize > Plugins** and open an installed plugin to see what it provides, turn it on or off, or remove it. Plugins you remove stay removed on this device, including ones your administrators set to install automatically.

## What plugins add in Claude for Government

A plugin's hooks run on your machine at defined points during a session. The connectors your administrators provide appear under **Customize > Connectors**. A plugin can also declare connectors of its own. Whether they connect depends on the settings your administrators choose.
