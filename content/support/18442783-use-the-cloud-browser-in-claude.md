# Use the cloud browser in Claude

The cloud browser is a browser that runs on Anthropic’s servers. This article explains how to take control of it, what Claude can see, and what to do before you hand it back.

The cloud browser is in beta and is rolling out gradually on Pro, Max, and Ultra plans, on web, desktop, and mobile. It isn't available on Free, Team, or Enterprise plans.

## What Claude can see

Claude can see what you enter, and any pages that are still open when you hand the browser back.

We try to hide passwords, card numbers, card security codes, and one-time codes. This depends on how the website is built, so don’t rely on it. For example, a one-time code can be hidden only if the website marks the field as a one-time code field.

## If you sign in to a site

If you sign in, Claude stays signed in to that site in that chat or task, and can act as you.

If you don’t want that, sign out before you hand the browser back. Closing the browser’s panel also hands control back to Claude, and so does the time limit, so sign out first. Sign out of the site, and of any account you used to sign in to it (such as Google or Apple). If it has already gone back to Claude, take control again and sign out.

## Take control of the cloud browser

You can take control of the cloud browser, for example to sign in to a site, and then hand it back to Claude. Follow these steps:

1. Open the cloud browser from its card in your chat or task:

  1. On web and desktop, select the side panel icon (its tooltip reads "Open browser in side panel").

  2. On iPhone and Android, tap the card, or "Open."

2. Select "Take control."

3. Complete your step, such as signing in. Claude can’t use the browser while you’re in control, but it can see what you enter.

4. Select "Hand back to Claude" (or "Hand back" on iPhone and Android).

**Note:** Control also goes back to Claude by itself after a time limit, or when you close the browser's panel. "Take control" shows only while a page is open in the cloud browser. If the browser has stopped, ask Claude to open the page again.
