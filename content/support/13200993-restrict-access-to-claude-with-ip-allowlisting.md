# Restrict access to Claude with IP allowlisting

IP allowlisting is available in public beta for Enterprise plans and Claude Platform organizations.

An IP allowlist limits access to Claude to the IP addresses your organization approves. Owners on Enterprise plans and Admins on Claude Platform can set up and manage their IP allowlist themselves, without going through Anthropic. For full documentation and setup guides, see **[IP allowlisting on Claude API Docs](https://platform.claude.com/docs/en/manage-claude/ip-allowlist)**.

**Important:** Artifacts shared outside your organization aren't limited by your allowlist. Learn more about **[managing sharing outside your organization](https://support.claude.com/en/articles/16994751-artifacts-admin-guide-for-team-and-enterprise-plans#h_fd0c095985)**.
